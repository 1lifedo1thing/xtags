Xtags — X 推文 AI 识别与过滤

识别疑似 AI 推文，减少阅读干扰
Xtags 在你浏览 X / Twitter 时，识别文字中疑似主要由 AI 撰写或大幅改写的内容。达到你设置的阈值后，自动折叠正文、媒体和互动区域，保留作者、时间及标签。AI 提示直接跟在原有标签后，点击“展开帖子”即可阅读。

按你的习惯过滤
• 自动折叠：分析完成后折叠疑似 AI 帖子，展开后保留淡红背景，可再次收起。
• 仅微红提示：保留正文，用淡红底色提醒。
• 仅标签：显示判断提示，不改变正文显示。
• 独立调整 AI 阈值，默认 0.85；调整阈值和模式复用已有判断，不因此重复请求 API。
• 本标签页记住手动展开选择；详情页默认展开。

长推文，展开前先看判断
对尚未展开的长推文，Xtags 使用 X 页面数据中已经提供的全文进行分析。全文暂不可用时会等待或重试，不把摘要当作全文判断。

辅助理解帖子意图
保留告知、说服、挑拨、推销、娱乐、其他六类意图及概率，并提供诱导愤怒、未披露推广提示。根据文字线索估计，不核实真实商业关系或帖子中的事实。

开始使用与费用
需要 Chrome 140+、网络和自备所选服务的 API key。默认使用 TypeSafe 的 Jev，支持兼容 TypeSafe System One 格式的自定义 HTTPS API，服务商可能收费。
1. 打开设置，保留默认服务，或保存兼容 API 的完整 HTTPS URL 并授权该域名。
2. 阅读数据说明和隐私政策，主动勾选同意项并点击“同意并启用”，再填写该服务的 key。
3. 启用 Xtags 并刷新 X 页面，按需设置过滤模式和 AI 阈值。
支持自动跟随 Chrome 界面语言或手动选择简体中文／英文；可暂停、跳过回复、清缓存及重试失败帖子。

数据与判断边界
分析并非在设备端完成。同意并启用后，页面已渲染帖子的正文和作者账号会直接发送给所选 API，包含可能不在视口内或你有权限访问的受保护帖子；折叠长文在展开前发送已有全文。API key 仅供扩展可信页面和后台读取，内容脚本只收到 key 是否已配置的状态。设置、key 和有容量上限的判断缓存存于浏览器本地，缓存不保存正文原文。开发者没有分类或遥测服务器；服务商会收到 IP 等连接信息。

AI 判断可能出错。分数是模型估计，不是经过验证的识别准确率；0.85 是初始展示阈值。标签不能证明文本来源，也不表示虚假或恶意。仅分析文本，不分析图片或视频；自动折叠在收到判断后发生。Xtags 为独立项目，与 X Corp 无关联。
