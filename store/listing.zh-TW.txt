Xtags

使用條件與資料說明
需要自備所選服務的 API key 並連接網路。預設使用 TypeSafe，也支援相容的自訂 HTTPS API，服務商可能收取費用。明確同意資料傳輸、設定 key 並啟用後，Xtags 會將 X / Twitter 頁面上已呈現貼文的正文與作者帳號傳送給所選服務進行分類，包括可能位於可視區域之外，以及你有權存取的受保護貼文。這不是裝置端本機分析。

協助理解貼文意圖
Xtags 在瀏覽 X 時為貼文加上簡潔的 AI 標籤，預設透過 TypeSafe 的 Jev 模型估計貼文是告知、說服、挑撥、推銷、娛樂，還是其他意圖。

另有三個訊號：誘導憤怒、未揭露推廣及機器生成。你可以調整訊號的顯示門檻，或查看其機率。標籤是模型估計，並非關於貼文或作者的已核實事實。

依照你的習慣調整
• 在彈出視窗暫停或繼續分類。
• 跳過被辨識為回覆的貼文。
• 調整三個提示訊號的門檻。
• 顯示或隱藏狀態面板。
• 重複使用本機分類快取，也能手動清除。
• 依瀏覽器介面語言自動選擇簡體中文或英文，也能手動切換。擴充功能介面目前不提供繁體中文。

開始使用
1. 從所選服務商取得 API key，預設服務商為 TypeSafe：https://typesafe.ai
2. 開啟 Xtags 彈出視窗並按下「设置」，保留官方服務，或儲存相容 TypeSafe 的完整 HTTPS API URL 並授權所選網域。更換 URL 會清除 key 並要求重新同意。然後閱讀資料說明及隱私權政策，勾選同意項並按下「同意並啟用」，再填入 key。
3. 啟用 Xtags，瀏覽 X / Twitter。
4. 視需要調整門檻與顯示設定。

隱私與使用限制
API key、設定，以及有容量上限的貼文 ID、評分與時間戳記快取儲存在瀏覽器本機。開發者不營運分析伺服器或統計服務；分類請求直接傳送給所選 API，該服務商也會接收 IP 位址等一般連線資訊。使用前請閱讀連結的隱私權政策。

Xtags 分析擷取出的貼文文字，不分析圖片或影片。回覆辨識及 AI 分類可能有誤。標籤無法證實欺騙、文字來源或作者的真實意圖。本專案與 X Corp 無關聯。
