Labels do not appear

  1. Open the popup, read the data notice, check the acknowledgement and click Agree and enable. Enter your TypeSafe API key. Existing users also need to consent when upgrading to 0.1.3.
  2. Open an X page containing text posts. Refresh existing pages after installing or updating the extension.
  3. Check Skip replies and the status panel. A 401 error usually indicates an invalid key; provider credits or access may also be required.
  4. After fixing credentials or a temporary network error, pause and resume to retry failed posts.

Stop requests or delete local data

Pause or withdraw consent first. Clear cache removes local judgments, not your API key. Empty the key field and move focus to save the change. Uninstall to remove the extension's local storage. Contact TypeSafe for provider-side deletion.

Report an issue

Include the extension and Chrome versions, operating system, selected language, steps to reproduce and a redacted screenshot. Labels are model estimates; a prediction alone does not establish wrongdoing or authorship.
